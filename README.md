# 4thel00z/homebrew-tap

Homebrew tap for [4thel00z](https://github.com/4thel00z) tools. GoReleaser updates the casks here on each release.

```sh
brew install 4thel00z/tap/<name>
```

| Cask | Description |
| --- | --- |
| [`timeout`](https://github.com/4thel00z/timeout) | GNU-compatible `timeout` for macOS |
